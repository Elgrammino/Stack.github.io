# Стек — Mnemonica

Автономное PWA-приложение для расчёта подснятия колоды Mnemonica. Все ресурсы локальные; серверной части и npm-зависимостей нет.

## Проверка

Откройте приложение через HTTPS (например, GitHub Pages) или запустите локальный HTTP-сервер: `python -m http.server 8877` и перейдите по адресу `http://localhost:8877/`. Файл `index.html` напрямую через `file://` не обеспечивает корректную работу модулей JavaScript и Service Worker.

## Публикация на GitHub Pages

Загрузите **содержимое** этой папки в корень репозитория (не саму папку). В GitHub выберите **Settings → Pages → Deploy from a branch → main → /(root)**. После первой полной загрузки PWA сохраняет карты и шрифты для офлайн-работы.

## Использование

1. Подтвердите нижнюю карту (изначально 9♦) или выберите другую.
2. Выберите карту зрителя и введите желаемую позицию сверху (1–52).
3. Приложение показывает число переносимых сверху вниз карт, карту-ориентир и новые верхнюю и нижнюю карты.
4. После физического подснятия нажмите новую нижнюю карту, чтобы сразу начать следующий расчёт. Кнопка «Начать заново» возвращает к первоначальной 9♦.

Проверяйте ввод с открытой цифровой клавиатурой и установку PWA на реальном телефоне отдельно от компьютерной эмуляции.

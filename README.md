# Стек — папки проекта

- **Для GitHub** — только файлы действующей версии приложения. Для публикации загрузить содержимое этой папки в корень репозитория.
- **Рабочий проект** — исходники, документы, проверки, варианты оформления и рабочие материалы. Здесь вносятся следующие изменения; перед публикацией обновляются файлы в «Для GitHub».

Внутри «Рабочего проекта» папка «Скриншоты» хранит изображения экранов, а «Материалы прежней сборки» — сохранённые файлы старой сборки.

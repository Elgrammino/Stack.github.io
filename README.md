# A.C.A.A.N.

Помощник для фокуса Any Card At Any Number с колодой в порядке Mnemonica. Приложение работает офлайн как PWA.

Исходная нижняя карта — 9♦. Выбор другой нижней карты включается отдельно на экране карты зрителя. После публикации новой версии установленное приложение предложит кнопку «Обновить».

Рабочая версия хранится в этом репозитории. Файлы приложения находятся в корне: `index.html`, `app.js`, `logic.js`, `sw.js`, `manifest.webmanifest`, а изображения и шрифты — в `cards/`, `icons/`, `fonts/`.
